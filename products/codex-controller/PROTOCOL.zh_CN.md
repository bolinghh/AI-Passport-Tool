# Passport 多应用协议 v2

保留加密认证 NUS。UUID 与有界 v1 帧封装不变：`a5 5a`、封装版本 `1`、类型 u8、
负载长度 u16、请求 u32、流 u32、序号 u16。多字节值均为大端。控制写入按20字节
分片，负载最多2048字节，Opus 最多256字节。应用版本单独协商；封装版本1
不代表兼容旧会话应用。

| ID | 消息 | 负载与行为 |
| --- | --- | --- |
| 1 | HELLO | 空请求/回声；麦克风关闭，尚未就绪 |
| 2–4 | 已废弃 | 原会话列表/选择/确认；永不复用，设备拒绝并断开 |
| 5 | MIC | 单字节0/1，非零请求；开启要求 stream=request |
| 6 | MIC_ACK | 状态 u8（0成功）、请求值 u8；必须匹配请求/流 |
| 7 | AUDIO | 原16 kHz单声道 Opus 60 ms帧、960样本、有界序号/队列 |
| 8 | HEARTBEAT | 空，每3秒；7秒静默超时 |
| 9 | ERROR | 关闭音频，不自动恢复 |
| 10 | CAPABILITIES | 严格 `[2,15]`：应用版本2，麦克风/时间/天气/设置能力；需回声 |
| 11 | TIME | UTC秒 u32（2020年起），有符号UTC偏移 i32（±86400）；设备按单调时钟走时 |
| 12 | WEATHER | 观测时间戳 u32、温度 i16（十分之一摄氏度，-1000…700）、WMO编码 u16、城市UTF-8字节数 u8、城市字节（1…48） |
| 13 | SETTINGS_UPDATE | 专注分钟 u8、休息分钟 u8，均1…120，非零请求 |
| 14 | DEVICE_STATUS | 电量 i8（-1未知）、RSSI i8（127未知）、页面 u8（主页/列表/番茄钟/麦克风/设置=0…4；像素伙伴=5、钓鱼=6）、麦克风状态 u8（关闭/准备/传音=0…2） |
| 15 | TIMER_STATUS | 阶段 u8（专注0/休息1）、状态 u8（待开始/运行/暂停/完成=0…3）、向上取整的剩余秒 u32、完成计数 u32 |
| 16 | SETTINGS_ACK | 状态 u8（0成功），匹配设置请求 |
| 17 | STOP | 空，桌面非零控制请求；立即清除设备采集/待确认流 |
| 18 | STOP_ACK | 空，匹配 STOP 请求；之后允许接收新的开启请求 |

## 桌面端 C ABI 恢复状态（0.2.1）

导出的 C 函数及 BLE 消息编号、负载不变。JSON 命令新增
`{"type":"retry"}`，立即重试当前目标。现有 `disconnect` 取消自动恢复；
`scan` 取消旧意图并扫描供用户选择；`connect` 选择目标并启用恢复。
可恢复的传输错误不会阻止后续命令；不新增持久化设置。

`connection` 快照保留 `phase`、`target`，新增 `retry_enabled`（布尔）、
`retry_count`（u32，就绪时清零）、`next_retry_at`（Unix秒或null）。
新增阶段 `Waiting`、`BluetoothOff`；`Connecting` 包含连接前的新一轮发现，
随后 `Syncing` 等待设置确认。调度使用单调时钟，Unix期限仅供界面展示。
手动取消及切换目标先使连接代次失效，防止排队的旧任务恢复音频。每次物理
连接拥有新的解析器、通知订阅、请求去重和音频流状态。旧回调不能将新代次
标记为就绪，也不能开始音频。恢复后重新发送能力、设置、时间和缓存天气，
不会发送麦克风启动请求。

## 就绪与失败

HELLO 后必须在7秒内完成能力协商。桌面只有收到能力与设置确认后才进入就绪。
旧固件不响应能力协商，新桌面会限时提示升级；旧桌面发送已废弃列表时，新固件
显示升级提示并断开。独立 `ble-check` 协商能力，但不配置或采集音频。

设备/计时遥测每秒发送。RSSI 在 LVGL 锁之外每5秒采样，不从“发现设备”推测，
也不绘制固定满格。天气超过一小时过期；非法更新不会部分修改状态。时间/偏移
每分钟及 Mac 时间/时区/唤醒变化时同步，离线时区转换需后续连接 Mac 同步。

桌面停止/退出/断开会立即关闭共享原子输出门控。STOP 还要求设备确认后才允许
新的麦克风开启，停止前排队的开启请求不会重开输出。STOP 确认超过3秒会断开。
离开设备麦克风页时，先本地关闭采集，再发送停止。保留流ID、请求去重、有界解析、
序号处理与出错关闭音频，不保存讲话。

番茄钟使用单调毫秒差，不依赖墙钟同步或 BLE。后台导航与断线不重置计时。
设置只影响待开始/下一阶段。完成只触发一次，不自动开启下一阶段；重启重置
本地计时和完成计数。

0.3.0离线应用仅在设备状态中新增页面编号5和6，信封、能力字节和已有页面编号
保持不变；当前0.2.x Mac核心已将页面字节作为不透明状态接收。不新增游戏远程
命令、进度上传或桌面权限；本地奖励与存档独立于 BLE。

## Swift/Rust 边界

`desktop/macos/Sources/CPassport/include/passport.h` 定义所有权约定。创建/销毁一个
句柄，异步提交带类型的 JSON 命令并轮询 JSON 快照；每个返回的 UTF-8 字符串
恰好释放一次，不在调用尚未结束时销毁句柄。Swift 管理界面、时间、天气 HTTP
与原生通知；Rust 独占 BLE、设置校验/持久化、Opus 和音频输出。
关闭窗口保留同一个核心；明确退出时先关闭音频，再把销毁移到 UI 主线程之外。
仅明确的 BlackHole 录回诊断需要音频输入权限，不采集默认麦克风。
