# Passport

AI Passport 三键随身桌面助手与原生 macOS 配套应用。240×320 像素风主页展示
蓝牙信号、电量、日期、时间和天气。确定键打开应用列表：番茄钟、麦克风、像素伙伴、迷你钓鱼、设置。
当前应用已移除会话名称、链接与打开 Codex 的功能。

0.2.1的视觉基础细化用户选中的[像素掌机概念](../../assets/images/passport-pixel-concept.png)：
厚实的时钟字形、带明暗层次的像素图标、真实 RSSI 信号条、电池图标和琥珀色整行
选框；确认与完成提醒有独立空间。不分配整屏位图，不新增后台动画。

## Mac 重连（桌面端 0.2.1）

重启设备时让 Passport 桌面端继续运行。Rust 核心等待所选设备的新广播，取得
当前蓝牙对象后，恢复设置、时间及缓存天气。麦克风采集和输出保持关闭，必须
在设备上重新开始传音。关闭窗口后菜单栏继续恢复连接；明确退出会取消恢复并释放连接。

设备页与菜单栏展示“等待设备”“正在重连”“正在同步”。**立即重试**跳过当前等待；
**停止重连／断开连接**关闭自动恢复，手动连接或重开应用后才重新启用。重新扫描也会
取消旧连接意图，方便选择设备。切换目标使旧尝试失效。权限、拒绝配对及协议错误
需要处理后点击立即重试，不会自动清除绑定。关闭蓝牙时暂停扫描，打开后继续。
其他扫描、连接或清理错误不会停止命令后台。重试间隔为1、2、4、8秒，最高15秒；
每轮扫描窗口3秒。已配对设备连接、服务发现和订阅各限时10秒，清理总计限时5秒。
首次配对保留90秒连接及60秒订阅窗口。

固件保持 **0.3.0**。无需新增配置键、变更游戏存档或分区、烧录固件；Windows
历史版本不变。有限时本地验收可用原生可执行文件参数
`--connection-log /tmp/passport-connection.jsonl`，仅记录连接阶段、重试次数、
麦克风开关、进程编号和可见窗口数量；不记录设备标识、配对值、天气、音频样本
或包内容。此功能需明确开启，仅为本地诊断记录。

## 设备操作

- 主页按确定打开应用列表；上下循环选择五项，确定进入。
- 长按确定逐级返回，松开长按不会额外触发点击。
- 番茄钟默认专注25分钟、休息5分钟；上下选择主操作或重置，确定执行。
  运行中重置需确认，上下取消。阶段完成后等待确认再开始下一阶段，不自动循环。
  返回其他页面或蓝牙断开仍继续计时；设备重启后回到待开始。
- 麦克风进入时保持关闭，确定开始/停止传音；退出应用、断线或音频错误会关闭
  采集，重连不自动恢复。
- 像素伙伴：上下选择喂食、陪玩、装扮，确定执行；长按确定返回。
- 迷你钓鱼：确定抛竿，浮漂下沉后在1.8秒咬钩窗口内按确定；过早或过晚收竿
  都会错过。待抛竿/结果页上下打开图鉴，图鉴中上下翻页、确定返回。
  长按确定离开并取消本次抛竿；等待时按键不会反复重抽鱼种。
- 设置包含亮度、连接信息、需确认的取消绑定与返回。

计时完成有可关闭的视觉提醒，Mac 在获得通知权限后可发送原生通知。
提醒不播放声音，包括麦克风传音期间。

## 伙伴与钓鱼（0.3.0）

两个应用均可离线运行，无需 Mac、同步时钟、声音、Wi-Fi 或云服务。伙伴初始有
3份零食；喂食消耗1份，获得5经验。陪玩展示开心动作，不刷经验。每次专注阶段
完成仅奖励一次20经验和2份零食，休息阶段不奖励。每100经验升一级，最高10级。
装扮在已解锁样式中循环：原样、2级围巾、4级星冠。不因离线饥饿或扣成长。

钓鱼等待2至5秒后进入1.8秒咬钩窗口。六种原创像素鱼的每竿出现概率依次为
40%、25%、17%、10%、6%、2%。钓到鱼获得8经验和1份零食；喂食不会消耗图鉴
收藏。未发现鱼种在图鉴中隐藏。番茄钟完成或安全配对会收起当前鱼竿，避免游戏
在提醒背后超时；单纯蓝牙断开不影响离线游玩。两个应用沿用现有150 ms渲染节奏，
不增加页面独立任务/定时器、音效或整屏缓冲。

成长、零食、装扮和六种鱼的收藏计数仅保存在设备 NVS `passport/play_v1`。
独立3 KB存档任务会合并修改：至少安静1.2秒（钓获结果立即请求存档）、每3秒最多提交一次；写入出错会重试，
采集/准备传音或抛竿期间不提交。关机前等待保存提示消失，突然断电可能丢失最近
尚未保存的奖励。存档为32字节带版本及 CRC 校验的记录，载入前验证；未知或损坏
记录保留原样并明确提示存档不可用，不静默重置或覆盖。每种鱼和零食上限999，
经验上限99,999。取消蓝牙绑定不会清除游戏进度。鱼竿、互动表情和菜单状态不持久化，
重启恢复成长收藏并回到待抛竿状态。

## Mac 原生配套应用

需要 macOS 13+、原生 Rust、Swift 命令行工具、CMake 和 Python 3.11+，不要求
安装完整 Xcode。在本产品目录运行：

```bash
bash tools/build-macos.sh
```

打开 `desktop/target/release/Passport.app`。这是本地临时签名构建，尚未公证发布。
SwiftUI 主窗口包含设备、麦克风与偏好设置；关闭窗口后菜单栏继续运行，明确退出
应用才停止输出并断开蓝牙。一次只运行一个桥接实例。

单独安装 [BlackHole 2ch](https://existential.audio/blackhole/)。麦克风页选择
BlackHole 2ch、保存输出并执行测试音/录回检查。目标语音应用选择 BlackHole 2ch
作为麦克风，手动打开语音输入，再使用 Passport 麦克风应用传音。
音频不保存，录回仅在内存使用明确选择的 BlackHole 虚拟输入，不改变系统默认
输入/输出设备。

偏好设置使用 Open-Meteo 搜索城市，不申请定位权限、不预设城市。明确选中城市；
字库不支持的名称可编辑设备显示别名。天气每30分钟刷新，HTTP 超时10秒；失败
保留数据时间并显示错误。设备天气超过一小时标记过期。数据来源：
[Open-Meteo](https://open-meteo.com/)，API 按非商业用途使用；商业分发前需复核条款。
时间/时区在连接、唤醒、系统时间/时区变化及每分钟跟随 Mac 同步。断开时设备按
最近同步的时钟和 UTC 偏移继续走时；后续时区或夏令时变化需要 Mac 再同步。
设备重启后显示未知时间，等待同步。

专注/休息时长可设为1至120分钟。保存后影响下一阶段，不修改正在运行或暂停的
阶段。亮度保存在设备上。

## 设置、协议与兼容

新偏好设置保存在
`~/Library/Application Support/passport-codex-controller/settings.json`。
只从旧 `config.json` 迁移设备标识和音频输出，旧文件保留，会话链接不会复制到
新设置或日志。保留原 Bundle ID 与蓝牙绑定，不自动重置绑定。

新版桌面和固件要求多应用 v2 能力协商。新旧组合会限时失败并提示升级，不回退
到旧会话清单；原会话消息编号作废，不复用。见[协议](PROTOCOL.zh_CN.md)与
[验证](VALIDATION.zh_CN.md)。

本轮只交付 Mac。`desktop/legacy/windows-main.rs` 保留原 Windows UI 源码作为
历史参考，不代表可构建或兼容 v2。冻结的[交接文档](HANDOFF.zh_CN.md)描述旧版本。

## 构建与测试

```bash
python3 tools/validate.py --host
# 激活 ESP-IDF 5.5.3 后：
python3 tools/validate.py --firmware
# 无 .git 源码包：在可丢弃副本运行根门禁
python3 tools/source-gate.py --mode=--all
```

主机验证还使用固件同样的24 KB绘图内存、RGB565和分块缓冲，实际渲染45种
LVGL 界面状态，检查时钟、图标、边框是否真正画出、当前字体字形覆盖与标签边界。
PPM 预览位于 `build-host/ui-preview/`，其中读数均为示例。需先通过固件构建解析
托管 LVGL 依赖。可单独运行：

```bash
cmake -S tests/preview -B build-host/preview
cmake --build build-host/preview --parallel 8
mkdir -p build-host/ui-preview
build-host/preview/screen_preview build-host/ui-preview
```

Mac 构建运行 Rust 核心测试，以及原生 Swift 可执行检查程序（在 `desktop/macos`
运行 `swift run PassportChecks`）。后者无需命令行工具缺少的 XCTest。
原生 Rust 产物使用 `desktop/target/macos13`，避免复用针对较新系统的旧依赖缓存。
CMake 4 下在全新目录直接运行 Cargo 时需设置 `CMAKE_POLICY_VERSION_MINIMUM=3.5`。
产品复用根 BSP 与8 MB NVS/PHY/factory 最小分区。固件门禁保留匹配合并镜像、
ELF 和 MAP；构建不会烧录。

诊断程序位于 `Passport.app/Contents/MacOS/PassportDiagnostics`：

```text
PassportDiagnostics devices
PassportDiagnostics inputs
PassportDiagnostics loopback "BlackHole 2ch" "BlackHole 2ch"
PassportDiagnostics ble-check
```

GUI 占用连接时不要运行 BLE 诊断。原生包分发仍需许可复核、签名/公证与真机验收。
